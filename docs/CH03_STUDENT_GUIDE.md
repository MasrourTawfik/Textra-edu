# Guide étudiant CH03 — édition pédagogique v3.0

Le cours PDF, le notebook intégral et ses deux jeux de données sont accessibles depuis [la page CH03](../chapters/CH03/README.md).

1. Lire progressivement le cours [PDF](../chapters/CH03/Trading_Intelligent_CH03_Cours_Progressif_Tawfik_Masrour_v3.0.pdf).
2. Ouvrir le [laboratoire intégral](../notebooks/CH03/CH03_Laboratoire_Integral_Volatilite_Risque_Tawfik_Masrour_STUDENT.ipynb) dans Jupyter ou [dans Colab](https://colab.research.google.com/github/MasrourTawfik/Textra-edu/blob/trading-intelligent/notebooks/CH03/CH03_Laboratoire_Integral_Volatilite_Risque_Tawfik_Masrour_STUDENT.ipynb).
3. Lire avant chaque exécution les cellules Markdown « Pourquoi ? », « Avant Python » et « À observer ».
4. Exécuter les cellules dans l'ordre. Tous les jeux de données essentiels peuvent être générés directement par le notebook.
5. Répondre aux arrêts de compréhension et conclure par une note de décision financière argumentée.

**Important :** les données sont simulées ; tous les résultats sont exclusivement pédagogiques. Le parcours CH03 actuel repose sur le laboratoire intégral et ses deux jeux de données synthétiques.
