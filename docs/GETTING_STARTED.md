# Bien démarrer — Trading Intelligent

## 1. Lire

Commencez par le chapitre PDF correspondant. Le livre présente les idées, les notations, les exemples et les limites avant le code.

## 2. Expérimenter

Utilisez ensuite le bouton **Open in Colab** depuis la page d'accueil. Le notebook étudiant reprend les mêmes notions et les met en pratique sur des données reproductibles.

## 3. Données

Chaque jeu de données possède un identifiant stable. Pour le chapitre 1 :

- **Identifiant :** `TI_CH01_MARKET_V1`
- **Fichier :** `TI_CH01_Market_Data_v1.csv`
- **Nature :** données pédagogiques synthétiques et déterministes.

Le notebook peut fonctionner même si le fichier CSV n'est pas présent localement : il sait reconstruire exactement la série de référence.

## 4. Travail personnel

Les cellules marquées comme exercices sont destinées à être complétées par le lecteur. Les solutions enseignant ne sont pas publiées dans cet espace.

## 5. Ordre recommandé

**Lire → exécuter → modifier → interpréter → revenir au livre.**

Le but n'est pas seulement d'obtenir un résultat numérique, mais de pouvoir expliquer :
- ce qui est calculé ;
- pourquoi cette transformation est légitime ;
- ce qui était réellement disponible au temps de la décision ;
- quelles hypothèses sont introduites ;
- quelles limites restent ouvertes.

## 6. En cas de difficulté

Avant de modifier le code, vérifiez :
1. que toutes les cellules précédentes ont été exécutées ;
2. que les imports ont réussi ;
3. que le notebook utilise bien Python 3 ;
4. que les données ont été chargées ou régénérées ;
5. que l'erreur n'est pas due à une modification locale.
